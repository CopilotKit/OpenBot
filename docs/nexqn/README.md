# NexQN AI documentation

NexQN AI is a private AI agent platform built on [CopilotKit OpenBot](https://github.com/CopilotKit/OpenBot)
(MIT). These documents cover what NexQN adds; the upstream documents one level up describe the base
system and are left unedited so upstream merges stay clean.
