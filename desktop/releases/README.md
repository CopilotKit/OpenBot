# OpenBot para macOS Intel

Instalador compilado para Macs Intel (`x86_64`):

- `OpenBot_0.2.0_x64.dmg`

Abra o arquivo `.dmg`, arraste o OpenBot para `Applications` e execute-o. Como este build não está assinado com um certificado Apple Developer ID, o macOS pode exigir que o primeiro acesso seja feito com botão direito em **Abrir**.
