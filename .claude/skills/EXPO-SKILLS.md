# Expo skills

The `expo-*` and `eas-*` skills in this folder are copied from Expo's official
[expo/skills](https://github.com/expo/skills) (`plugins/expo/skills`, commit a9e5bd3), under the MIT
license in `EXPO-SKILLS-LICENSE`. They help a coding agent build OpenBot's Expo phone app in
`mobile/`. To update them, copy that folder again.
