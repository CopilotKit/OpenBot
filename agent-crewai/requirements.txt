# with `APIConnectionError: cannot import name 'CacheableResult' from 'mcp.types'` — a model call
# reporting a missing import, which reads as a network fault and is not one.
#

# ag-ui-crewai back to 0.3.1 and crewai to 1.6.1. 1.105.1 does not reference the symbol at all and
# leaves every other version exactly where it was. Lift this when ag-ui-crewai supports mcp 2.
